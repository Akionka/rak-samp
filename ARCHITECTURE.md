# Architecture

Each ASI loads independently. Only the host links the native hook backend;
plugins use the public, versioned SDK package.

## Components

| Area | Location | Purpose |
| --- | --- | --- |
| Bootstrap and ABI | `src/lib.rs`, `src/host_api/mod.rs`, `src/host_api/animations.rs`, `src/host_api/chat_input.rs`, `src/host_api/commands.rs`, `src/host_api/connection.rs`, `src/host_api/conversions.rs`, `src/host_api/dialog.rs`, `src/host_api/environment.rs`, `src/host_api/events.rs`, `src/host_api/handles.rs`, `src/host_api/local_commands.rs`, `src/host_api/local_state.rs`, `src/host_api/messages.rs`, `src/host_api/network.rs`, `src/host_api/player_commands.rs`, `src/host_api/players.rs`, `src/host_api/pools.rs`, `src/host_api/raw.rs`, `src/host_api/snapshots.rs`, `src/host_api/textdraws.rs`, `src/host_api/text_labels.rs`, `src/logging.rs` | Start outside `DllMain`, publish status, poll and synchronize command receipts, convert owned snapshots into fixed ABI output storage, operate on callback-local bitstreams and native string codecs, read SAMP game state, server metadata, version, cached chat input, connection lifecycle commands, local-player actions, attributes, names, display-message, and textdraw commands, queue local chat-input, local UI, text-label, and dialog commands, read and resolve cached local animations, expose local UI state, the active-dialog core, and detailed dialog snapshots, perform forward/reverse handle lookups, serve local-player snapshots, player-pool scalars, pool existence, and pooled-record snapshots, send or emulate packet/RPC traffic, expose validated opaque native addresses, and export `SampClientSdkApiV1`. |
| Runtime | `src/runtime.rs`, `src/runtime/errors.rs`, `src/runtime/options.rs`, `src/event.rs`, `src/bitstream.rs` | Own bounded event data, isolate runtime failures and send policy, dispatch listeners, and send exact RakNet payloads. |
| Native backend | `src/platform/win32/mod.rs`, `src/platform/win32/chat_entries.rs`, `src/platform/win32/commands.rs`, `src/platform/win32/requests.rs`, `src/platform/win32/reads.rs`, `src/platform/win32/gangzones.rs`, `src/platform/win32/handles.rs`, `src/platform/win32/hooks.rs`, `src/platform/win32/objects.rs`, `src/platform/win32/packets.rs`, `src/platform/win32/players.rs`, `src/platform/win32/text_labels.rs`, `src/platform/win32/textdraws.rs`, `src/platform/win32/vehicles.rs`, `src/platform/win32/r1_client.rs`, `src/platform/win32/r1_client/addresses.rs`, `src/platform/win32/r1_client/memory.rs`, `src/client.rs` | Capture immutable attach-time configuration separately from mutable backend state; select networking offsets, own hook lifecycle and tick execution, keep native detours in `hooks.rs`, validate and dispatch native bitstreams/raw packets through listeners, perform native outbound sends and incoming packet/RPC emulation, bound producer-side game/cache requests, expose published scalar, snapshot, animation-catalog, chat-history, gangzone, handle-cache, object, player, text-label, textdraw, and vehicle reads, isolate approved R1/GTA addresses and native layouts, and validate every direct access through guarded memory helpers. |
